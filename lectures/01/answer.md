## 宿題

- 取り組んだレベル：基礎 
- やったこと：
  同じ質問「LoRAとは何ですか？」を、AIE_MODEL を変えて3回ずつ実行した。変えた条件はモデルだけ（temperatureは変更していない）。
  - 使ったモデル: gemini-3.8-flash、gemini-3.5-flash-lite、gemini-3.1-flash-lite
  - 実行方法: `AIE_MODEL=<モデル名> uv run python -m app.ask "LoRAとは何ですか？"`
  - 実行回数: 各モデル3回、合計9回
- 結果：
 同じモデルに同じ質問をしても、3回の回答は毎回違った。
  - 同じモデルでの違い（ばらつき）: 例え話が毎回変わった（3.8-flashは「透明シート」「辞書」「教科書」、3.1-flash-liteは「付箋」「プラグイン」など）。読み仮名の表記や、挙げる具体例（LLaMA、Gemma、Civitaiなど）も回ごとに違った。さらに、3.8-flashは3回中1回だけ通信分野のLoRaにも触れた。
  - モデルによる違い: 3.8-flashは情報量が多く、2つの意味の区別や、低ランク近似の数学的な説明まで踏み込む回があった。3.5-flash-liteは例え話中心で、仕組みの説明は簡潔だった。3.1-flash-liteは軽量モデルだが、行列やアダプター層など、技術的な説明を含む回が多かった。
  - 共通点: どのモデルも、見出し・箇条書き・太字を使った同じような構成で、最後に「まとめ」を付けた。
- 気づき・疑問：
 - 回答の骨格は安定していたが、数値は回答ごとに変わった。数値をそのまま信じず、論文などの一次資料で確認する必要がある。
  - 軽量モデル（flash-lite）の方が、技術的に詳しい説明を含む回もあった。モデルの大きさと説明の深さは、必ずしも比例しないように思える。
  - temperatureを変えると、ばらつきがどう変わるのか試してみたい。
